# Phase 018: 반응형/UX 개선

## 개요

사용자 경험을 전반적으로 향상시키기 위해 토스트 알림 시스템, 스켈레톤 로딩, 모바일 하단 내비게이션을 구현했습니다.

## 구현 범위

### 1. 토스트 알림 시스템

**라이브러리**: `sonner` (경량 토스트 라이브러리)

**파일**: `components/providers/ToastProvider.tsx`

- `Toaster` 컴포넌트를 앱 전역에 제공
- 우측 상단 위치, 3초 자동 닫힘, 닫기 버튼
- richColors 모드: 성공(초록), 에러(빨강), 정보(파랑) 자동 스타일링

**적용 범위**:

| 페이지/컴포넌트 | 성공 토스트 | 에러 토스트 |
|---|---|---|
| 프롬프트 상세 | 구매 완료, 즐겨찾기 추가/제거, 삭제 완료 | 구매 실패, 즐겨찾기 실패, 삭제 실패 |
| 설정 페이지 | 프로필 업데이트 완료, 비밀번호 변경 완료 | 프로필 업데이트 실패 |
| 리뷰 섹션 | 리뷰 등록/수정/삭제 완료 | 리뷰 등록/수정/삭제 실패 |
| 관리자 대시보드 | 관리자 권한 변경, 프롬프트 상태 변경 | 각 작업 실패 |

### 2. 스켈레톤 로딩

**파일**: `components/ui/skeleton.tsx`

- shadcn/ui 표준 Skeleton 컴포넌트
- `animate-pulse` 애니메이션 기반

**적용 페이지**:

1. **랜딩 페이지** (`app/page.tsx`)
   - 인기/최신 프롬프트 섹션에 4개씩 스켈레톤 카드
   - 데이터 로딩 완료 시 실제 PromptCard로 전환

2. **프롬프트 상세 페이지** (`app/prompts/[id]/page.tsx`)
   - 3-column 레이아웃 유지하는 스켈레톤
   - 제목, 설명, 미리보기, 본문, 사이드바 카드 포함

3. **관리자 대시보드** (`app/admin/page.tsx`)
   - 통계 카드 그리드 스켈레톤 (8개)
   - 최근 활동 리스트 스켈레톤

4. **관리자 사용자/프롬프트** (`app/admin/users/page.tsx`, `app/admin/prompts/page.tsx`)
   - 아바타 + 텍스트 라인 조합 스켈레톤
   - 5행 리스트 스켈레톤

### 3. 모바일 하단 내비게이션

**파일**: `components/layout/Header.tsx`

기존 조건부(user 전용) 상단 모바일 네비를 고정 하단 네비게이션 바로 교체:

- **위치**: 화면 하단 고정 (`fixed bottom-0`)
- **배경**: 반투명 블러 (`bg-white/95 backdrop-blur-sm`)
- **Safe Area**: iOS notch 대응 (`safe-area-bottom`)
- **메뉴 구성**:
  - 로그인 시: 홈, 둘러보기, 등록(플로팅 원형 버튼), 즐겨찾기, 프로필
  - 비로그인 시: 홈, 둘러보기, 로그인, 시작하기
- **등록 버튼**: 원형 그라데이션 버튼으로 강조 (약간 위로 떠오름)
- **활성 상태**: 현재 경로에 맞는 아이콘 색상 변경 (primary)

**CSS 변경** (`app/globals.css`):
- `.safe-area-bottom` 유틸리티 클래스 추가
- 모바일에서 `main` 요소에 하단 패딩 추가 (`padding-bottom: 4.5rem`)

### 4. 기타 UX 개선

- **관리자 패널 링크**: 프로필 드롭다운에 관리자 전용 메뉴 추가 (빨간색 Shield 아이콘)
- **루트 레이아웃**: `ToastProvider` 통합
- **라우트 보호 강화**: `/bookmarks`, `/points` 경로도 미들웨어 보호 대상 추가

## 기술적 결정

### sonner 선택 이유

- 번들 크기가 작고 (< 5KB gzipped) 설정이 최소화됨
- shadcn/ui 생태계와 자연스럽게 통합
- `toast.success()`, `toast.error()` 등 직관적인 API
- 기존 인라인 상태 메시지와 병행 가능 (기존 UX 유지하면서 추가 피드백)

### 모바일 네비게이션 설계

- 비로그인 사용자에게도 기본 탐색 제공 (홈, 둘러보기)
- 등록 버튼을 원형으로 돌출시켜 핵심 CTA 강조
- 5개 이하 메뉴로 제한하여 터치 영역 확보
- `md:hidden` + `fixed`로 데스크톱에서는 표시하지 않음
